# 间隔重复——遗忘曲线与记忆调度

## 为什么要间隔

遗忘是**生理默认值**，不是意志力缺陷。新学内容在最初数小时遗忘最快，一天后大约只剩三分之一，随后放缓。

既然遗忘有节奏，复习就该卡在节奏上：最优时机是**快要忘记但还没完全忘记**的那一刻。
- 太早 → 记忆增益很小（浪费）
- 太晚 → 等于重新学一遍

## 间隔序列

学完当天 → 第 1 天 → 第 3 天 → 第 7 天 → 第 15 天 → 第 30 天

每次成功回忆后，下次间隔可继续拉长。依据：每次成功提取都会**削弱遗忘曲线的斜率**。
反之，某次完全想不起来，间隔就该缩短回去 —— 这是一个自适应过程，不是固定日程。

## 最关键的一层：必须回忆，不能重读

重读会带来强烈的熟悉感，让人误以为自己记住了。但**熟悉感 ≠ 可提取性**。

起作用的是主动回忆：合上材料，先努力想起来，再对照检查。"努力想"的过程本身才是记忆被强化的时刻。

## 与主动回忆的分工

两者是配套关系，各管一件事：

| | 管什么 |
|---|---|
| 间隔重复 | **什么时候**复习 |
| 主动回忆 | **怎么**复习 |

## 常见误用

- 用在一次性信息上（它只适合需长期保留的核心知识）
- 只做卡片不做应用检验 → 只训练了识别
- 贪多：每天新增几百张卡 → 复习队列崩溃 → 整件事被放弃
