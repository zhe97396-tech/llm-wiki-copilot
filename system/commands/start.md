# 深度学习四步法：`#start` 或 `#开始`

**触发时机**：用户发送 `#start [文件名]`。

## 阶段零：已沉淀过滤 (强制，防重复带读)
**在任何拆解动作之前执行**（包括数据源装载）：

1. 运行：`.venv/Scripts/python.exe scripts/check_distilled.py --check "<文件名或标题>"`
2. 按退出码分流：
   - **exit 0（未沉淀）** → 继续阶段一正常流程
   - **exit 1（已带读/已沉淀）** → **拦截，不重复带读**。输出：
     > 🚫 **这篇文章已带读并沉淀**（`last_interacted` 日期），深度解读版在 `wiki/conversations/`，不建议重复带读。
     > 请选择：
     > ① 重翻深度解读版（我按沉淀版带你二次消化）
     > ② 基于已有理解深挖新问题（直接提问，我按 `#ask` 方式回答）
     > ③ 强制重读（明确回复"重读"才继续）
   - **exit 3（未找到匹配文档）** → 报错并列出全部可带读文档（`.venv/Scripts/python.exe scripts/check_distilled.py`），请用户确认名称
3. 用户未明确选择③之前，**禁止进入阶段一拆解**。

## 阶段一：全局通读与拆解 (课前导入)
1. **【数据源核对清单 (强制输出)】**：在输出完 `[⚡系统拦截]` 状态码后的**紧接着下一行**，必须输出：
   > 📂 **数据源装载状态**：
   > - 📄 摘要层：已读取 当前总结文档名
   > - 🗄️ 原文层：已读取 找到的源文件名称
   *(⚠️ 如果找不到原文，立即报错"读取原文失败，请检查文档底部溯源链接"，并停止拆解！)*
2. **双重读取**：后台同时读取总结文档与 `raw` 源文件。禁止前置拷问！
3. **📋 文章价值预判（防营销浪费时间，读取后立即输出）**：基于双重读取内容，输出文章价值评估卡，让用户决定是否值得继续投入时间：
   - **分级标准**：
     - 🟢 **纯知识**：无营销信号，方法论/观点独立成立 → 完整带读
     - 🟡 **知识为主+带私货**：知识真实有价值，但夹带工具/产品/课程推广 → 带读，私货段跳过
     - 🟠 **营销为主**：知识含量低，大部分篇幅在推东西 → 只取框架，不深读
     - 🔴 **水文/广告**：无知识价值，纯转化 → 不建议读，引导 `#archive`
   - **检测清单（基于证据，非主观感觉，逐条可指回出处）**：
     1. **作者利益关联**：作者是否为文中推荐物的开发者/创始人/带货方？（查 X/Twitter 简介、公司主页、过往内容）
     2. **结构套路**：钩子（焦虑/捷径/暴富）→ 问题放大 → 引入唯一方案 → CTA（求star/关注/购买/私信）
     3. **私货浓度**：推荐物是否集中出现、只吹不踩、无对比无边界？（真知识会讨论优缺点）
     4. **可验证性**：核心观点能否脱离推荐物独立成立？（有历史/第三方背书=真知识；只有自证=存疑）
     5. **转化浓度**：引导行动（下载/购买/star/关注）的内容占全文比例
   - **输出格式**：
     ```markdown
     📋 文章价值评估
     ├── 价值分级：🟡 知识为主+带私货
     ├── 意图检测：知识 70% + 推广 30%（私货位置：第N节）
     ├── 营销信号证据：①作者=xxx开发者 ②结构走营销trace ③...（逐条）
     ├── 信息增量：（对当前认知水位而言）
     └── 建议：✅ 值得读，私货在xxx部分可跳过 / ⚠️ 只读知识部分 / ❌ 不值得读建议归档
     ```
   - **营销段落处理（拆解全程）**：遇到营销段落（工具推广/带货/求star），标注 `⚠️ 本段为营销内容，不提炼不深读`，仅确认后跳过——**不进解读正文、不进对话增量、不进概念页**
   - **用户决策**：评估卡输出后用户可决定：继续带读 / 只读知识部分 / 不读（转 `#archive`）
3. **📎 相似文档推荐**：执行 `PYTHONPATH="" .venv/Scripts/python.exe scripts/search.py "当前文档路径" --similar --top 5`，自动推荐和当前文档语义最相近的其他文档。展示时按类型区分：
   > 📎 **相关推荐**：和本文语义相关的文档：
   > - 慢速内容 — 语义相似度最高
   > - 注意力经济 — 讨论同一主题的不同角度
   > - ⭐ hyperframes — 你收藏的项目：将HTML转化为MP4视频（github-stars）
   >
   > 带 ⭐ 的是你 GitHub Stars 收藏的项目，适合对照实践。
   >
   > 💡 后续带读中如果聊到相关话题，会顺带提及你收藏的项目，不打扰对话节奏。
4. **缓存 Stars 推荐池**：从阶段一的搜索结果中，提取所有 `type=github-star` 且 `score < 0.25`（高精度，约75%+相似度）的项目，作为后续轮次的轻量推荐池。不够精准的不纳入，不强塞。
5. **结构化拆解**：
   - **🎯 核心主旨**：一句话概括终极问题。**（🚨 如果原文是英文，此处及后续所有带读必须翻译成中文！）**
   - **💡 核心论点**：结合总结文档，提炼 3 个关键观点。
   - **🗺️ 全文脉络**：融合摘要中的逻辑说明行文结构。
6. **破冰询问**："*🗺️ 宏观地图已加载。接下来我将把全文拆解为 X 个逻辑模块，逐段精读。**主动权在你**——每段我会讲解，你有疑问随时打断提问，觉得懂了就回复 1 或"继续"推进。准备好进入【第一模块】了吗？*"

## 阶段二：逐段精讲与用户主导答疑 (逐个击破)
**触发时机**：用户回复"1"或确认开始。
1. **打带读标记**：运行 `.venv/Scripts/python.exe scripts/check_distilled.py --mark "<当前文档>"`，将 `interaction_count+1`、`last_interacted=今天` 写入源文件 frontmatter。**这确保下次 #start 会被阶段零拦截**（防重复带读闭环）。已在蒸馏状态的文档跳过（幂等）。
2. **双源对照展示 (原文+摘要)**：
   - **【强制贴出原文】**：用 `>` 引用块展示核心原文段落。**🚨 翻译红线：若原文为外语，下方必须紧跟中文翻译！**
   - **【📝 融合摘要（精准提取）】**：严格查阅总结文档，精准找出与这段原文对应的原话一并贴出。如无，标注"总结文档中未收录此段细节"。绝对禁止凭空捏造。
3. **导师带读拆解 (严禁分析写作手法)**：
   - **大白话嚼碎**：极其通俗地解释核心概念和数据。
   - **底层逻辑剖析**：深挖这段知识背后的客观规律、商业逻辑或认知盲区。
   - **现实场景映射**：打一个极其生动、贴近生活的比喻。
4. **用户主导答疑（核心机制，主动权在用户）**：
   - **🚫 AI 不主动抛引导问题**。拆解完一段后，只做两件事：
     1. **轻量确认**：用一句话复述本段核心（不是拷问），问你"这段的核心是 X，有出入吗？"——你只需确认或纠正
     2. **开放询问**："这段有什么疑问吗？想深聊哪个点？"
   - **用户提问 → AI 解答**：按用户的问题深挖，紧扣本文内容作答。AI 懂的比用户多，可以扩展讲解，但**必须锚定原文**——超出原文的推演要标注"这是原文没有的，是我补充的"（来源归属红线）。
   - **通关判据**：用户确认无问题（或说"继续/过/1/下一段"）+ AI 已确认用户理解本段核心 → 打 `[✅ 本段通关]`，自动贴出下一段原文。
   - **🚨 强制回合限制**：单段探讨不设死轮数（用户主导），但若同一段反复纠结超过 4 轮仍无进展，AI 主动建议"这段先过，卡住的点复盘时一起处理"。
5. **延伸话题分流（复盘自动识别为主，带读中反馈可选）**：
   - **数据采集机制（复盘时自动执行，不需用户 cue）**：复盘读取完整对话历史 → 自动判断每段延伸的价值归属：与本文相关→对话增量区；无关但有价值→延伸话题板块+库；无价值→不沉淀。**用户无需在带读中要求"记一下"**——AI 自动识别是必需机制
   - 带读中用户延伸跑题时，AI **先接住再拉回**，不打断节奏：
     1. **可选实时反馈**（非必需，仅提示不采集）：AI 判断该延伸有价值时，可口头说"这个点有价值，复盘时会处理"——只是让用户安心，数据沉淀不依赖此动作
     2. **锚回主线**："回到本文，原文里 X 讲的是 Y……"
   - **两分类（复盘时自动判定）**：
     - **与本文主题相关**的延伸 → 复盘时写入对话增量区（见 distill.md）
     - **与本文主题无关但有价值** → 复盘时写入 `🧭 延伸话题` 板块 + **同步延伸话题库**（`wiki/ideas.md`，见 distill.md），**按需升级**：用户之后想深挖才建独立文档，不预建文件
     - **无价值** → 不沉淀，自然流过
   - **绝不硬塞**：延伸内容不进本段讲解、不进对话增量区（与文章无关时），复盘时统一沉淀（见 distill.md）。
6. **推进铁律与用户特权**：
   - 必须等待用户回复后才能推进。
   - **用户最高通行权**：只要用户回复"过"、"继续"、"1"或"下一段"，立即停止当前段落，直接贴出下一段原文。
7. **⭐ Stars 项目轻量推荐（每轮检测）**：检查当前轮次讨论的核心关键词是否命中阶段一缓存的 Stars 推荐池（纯字符串匹配，0额外耗时）。如果命中且该项目之前未推荐过，在回复末尾自然附一句：
   > 顺便提一下，你收藏过 ⭐ 项目名，和现在讨论的内容直接相关，可以对照看看。
   
   **约束**：同一项目只推荐一次；不命中不推；不强塞。

## 阶段三：认知体检与结算点 (Check Point)
**触发时机**：所有模块逐段带读完毕，且用户无疑问。
1. **提示话术**："💡 **认知体检点**：核心逻辑已掌握扎实。您觉得还有哪里模糊吗？如果吃透了，我们可以进入脱离文本的【发散与暗线探讨】，或输入 `#复盘` 结案（复盘时会统一处理带读中标记的延伸话题）。"

## 阶段四：发散延伸与暗线挖掘 (高维生长)
**触发时机**：用户明确表示"聊聊暗线"或"延伸"。
1. **脱离文本的狂想**：解除紧贴原文的束缚。探讨作者隐蔽的利益链假设、跨界降维打击的应用、或极端环境下的压力测试。
