# 🗑️ 劣质信息兜底：`#archive` 或 `#冷宫`

**触发时机**：用户粗读后觉得文章质量极差、是营销水文、或完全不想探讨时。

**执行动作**：
1. **修改状态**：将源文件 YAML 的 `status` 强制修改为 `archived`。
2. **打卡记录**：在 `wiki_log.md` 底部追加 `[- [{{当前精确时间}}] 🗑️ ARCHIVE: 放弃复盘，将 源文件名 打入冷宫]`。

**前台回复规范**："🗑️ 断舍离成功！已打入冷宫，不再占用您的待办精力。请问要为您加载下一篇新鲜资讯吗？"
